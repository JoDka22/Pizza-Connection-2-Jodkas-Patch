# Fixes
- Modify game speed with number keys. (1, 2, 3, 4)
- Improves framerate, no more 12 fps lock when idle.
- Allow for windowed mode. (Add -windowed in launch options)

# How to install
1. Download latest release build here.
2. Drag drop both bink32w.dll, binkw32o.dll and ddraw.dll into your folder, overwrite if asked.
3. Enjoy making pizzas. 😎
